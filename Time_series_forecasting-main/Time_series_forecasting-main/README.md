## 🌟 Overview

The project demonstrates two approaches for stock price prediction:
- **ARIMA**: Captures linear trends in the data.
- **LSTM**: Handles complex, non-linear patterns in time series data.

It includes:
- Data preprocessing steps like handling missing values, stationarity checks, and Min-Max Scaling.
- Performance evaluation using metrics like **Mean Absolute Error (MAE)**, **Root Mean Squared Error (RMSE)**, and **Mean Absolute Percentage Error (MAPE)**.
- A comparison of ARIMA and LSTM models to identify their strengths and limitations.

## 📊 Dataset

The dataset used in this project contains historical stock price data from **Google**, including:
- **Date**: Timestamps for each observation.
- **Average Price**: Historical stock prices.

You can download the dataset from [Yahoo Finance](https://finance.yahoo.com/).
